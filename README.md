# لوحة استضافة البوتات (Bot Host Panel)

لوحة ويب خفيفة لاستضافة أكثر من بوت (Node.js أو Python) على نفس السيرفر:
- رفع بوت (ملف واحد أو ZIP لمشروع كامل)
- كشف نوع البوت (Node/Python) وملف التشغيل تلقائياً
- تثبيت المكتبات تلقائياً (npm install / pip install -r requirements.txt)
- تشغيل / إيقاف / إعادة تشغيل كل بوت من الواجهة
- محرر ملفات مدمج: تعدل أي ملف وتحفظ، ويقدر يسوي ريستارت تلقائي بعد الحفظ
- سجل تشغيل حي (Logs) لكل بوت
- حماية بكلمة مرور دخول واحدة

## كلمة المرور الافتراضية
```
Pablo
```
يمكن تغييرها عبر متغير بيئة `PANEL_PASSWORD` بدون تعديل الكود.

## التشغيل محلياً
```bash
npm install
npm start
```
ثم افتح: http://localhost:3000

## النشر على Railway
1. ارفع هذا المجلد كمشروع على GitHub.
2. أنشئ مشروع جديد في Railway واربطه بالمستودع.
3. أضف متغير بيئة (اختياري) لتغيير كلمة المرور:
   - `PANEL_PASSWORD=Pablo`
4. Railway سيستخدم ملف `nixpacks.toml` تلقائياً لتوفير Node.js و Python معاً.
5. بعد النشر، ادخل على الرابط الذي يعطيك إياه Railway، وسجل الدخول بكلمة المرور.

## ملاحظات مهمة
- يوجد حد أقصى افتراضي 30 بوت في نفس الوقت (`MAX_BOTS` داخل `server.js`) لحماية الاستضافة المجانية من الانهيار، تقدر تزيده أو تقلله حسب موارد سيرفرك.
- كل بوت يشتغل كعملية (process) منفصلة داخل نفس السيرفر، فكن منتبه لموارد الذاكرة/المعالج في الخطة المجانية.
- ملفات كل بوت تُحفظ داخل `bots/<id>/` وبيانات اللوحة تُحفظ في ملف خفيف `data/db.json` (بدون الحاجة لقاعدة بيانات خارجية).
- عند حفظ تعديل على ملف مع تفعيل خيار "إعادة تشغيل بعد الحفظ"، سيتم إيقاف العملية القديمة وتشغيل نسخة جديدة تلقائياً بنفس الإعدادات.
